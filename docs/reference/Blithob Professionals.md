# blithobprofessionals.com Scope and Pricing

## 1. Project Overview

We will build **blithobprofessionals.com**, a workforce operations platform for managing trained remote workers, assigning them to opportunities, tracking their work, reviewing submissions, and recording payouts.

The platform will be used internally by the founder/admin and workers. UK clients will not need to log into the system. The founder will continue managing client relationships directly, while blithobprofessionals.com helps organize the internal delivery process.

The project will be delivered in two phases:

- **Phase 1:** Public website, core workforce operations system, SEO setup, and email notifications.
- **Phase 2:** Paystack integration and selected automation improvements.

## 2. Phase 1: Website and Core Workforce Operations System

**Phase 1 Cost: $1,200**

Phase 1 covers the public-facing website, the main internal application, SEO setup, and the notification structure needed to run the business workflow professionally.

### Public Website and Landing Page

blithobprofessionals.com will include a public-facing website that introduces the business and gives the platform a professional online presence.

The website will include:

- Homepage/landing page.
- Clear explanation of the business and services.
- Service sections for the types of remote support offered.
- Call-to-action buttons.
- Contact section or enquiry direction.
- Login entry point into the internal app.
- Mobile-responsive design.

This gives the business a proper front door online while keeping the operations platform available only to approved users.

### Admin Dashboard

The founder/admin will have a dashboard showing the key parts of the operation, including:

- Workers in training.
- Workers ready for work.
- Active opportunities.
- Work in progress.
- Work awaiting review.
- Completed work.
- Pending payout records.
- Important reminders.

### Worker Management

The admin will be able to create and manage worker profiles.

Each worker profile will include:

- Name and contact information.
- Worker status.
- Skills or service categories.
- Training progress.
- Approved service areas.
- Assigned opportunities.
- Work history.
- Payout history.
- Admin notes.

### Service Categories

The admin will be able to manage the types of services the business offers, such as:

- Social media management.
- Content creation.
- Digital marketing support.
- Data entry.
- Virtual assistance.
- Other remote support services.

These service categories will help organize training, worker readiness, and opportunity matching.

### Training Readiness Tracks

The platform will include a simple training checklist system.

For each service category, the admin can define the steps a worker must complete before being approved for that type of work.

Example training steps may include:

- Attend onboarding or orientation.
- Review service expectations.
- Complete a sample task.
- Submit practice work.
- Receive feedback.
- Pass admin review.

Once a worker completes the required steps, the admin can mark the worker as ready for that service category.

### Opportunity Management

The admin will be able to create opportunities for work received from UK clients.

Each opportunity will include:

- Opportunity title.
- Service category.
- Work description.
- Expected output.
- Deadline.
- Required skill or readiness level.
- Worker pay amount.
- Current status.
- Assigned worker.

### Worker Matching

The platform will help the admin identify suitable workers for each opportunity.

Matching will be based on:

- Approved service category.
- Worker readiness.
- Worker workload.
- Past completion history.
- Admin selection.

The system will show eligible workers, but the admin will make the final assignment.

### Assignment and Work Tracking

Once a worker is assigned to an opportunity, the work will move through clear statuses:

- Assigned.
- In progress.
- Submitted.
- Needs revision.
- Accepted.
- Completed.

Workers will be able to view assigned work, update progress, and submit work notes, files, or links.

### Review and Quality Control

The admin will be able to review submitted work before it is marked as completed.

The review flow will support:

- Review notes.
- Revision requests.
- Approval status.
- Completion status.

### Payout Tracking

Phase 1 will include payout tracking, but not automatic payment processing.

For each completed opportunity, the platform will record:

- Worker name.
- Opportunity title.
- Agreed worker pay.
- Due date.
- Payment status.
- Date paid.
- Payment reference or note.

The admin can mark payouts as pending or paid after payment is handled outside the platform.

### Basic Reminders

The platform will include basic reminders for important actions, such as:

- Opportunity deadline approaching.
- Work submitted and waiting for review.
- Payout pending.
- Training checklist waiting for approval.

### Email Notifications

Phase 1 will include email notification setup for important platform activities.

Email notifications may cover:

- New worker account or onboarding message.
- Training checklist updates.
- Opportunity assignment.
- Work submitted for review.
- Revision request.
- Work accepted or completed.
- Payout status update.
- Admin reminders for pending actions.

The email setup can use the business's professional email identity so notifications look credible and consistent with the blithobprofessionals.com brand.

### SEO Setup

Phase 1 will include basic SEO setup for the public website.

This will include:

- SEO-friendly page titles and descriptions.
- Proper heading structure.
- Search-friendly service content.
- Mobile-friendly page structure.
- Basic technical SEO setup.
- Sitemap and indexing readiness where applicable.
- Search engine visibility setup for the public website.

The goal is to make the website well-structured for discovery on search platforms. Search ranking depends on competition, content depth, backlinks, domain age, and ongoing activity, but the Phase 1 build will include the right technical and content foundation.

## 3. Phase 2: Paystack Integration and Improvements

**Phase 2 Additional Cost: $300**

Phase 2 will be added after Phase 1 is completed and approved.

This phase will include:

- Paystack integration for worker payout support.
- Payment status updates linked to payout records.
- Improved payout workflow.
- Basic worker performance tracking.
- Improved onboarding flow for new workers.

Phase 2 is intended to complete the platform with payment support and a few useful improvements, without turning the project into a larger or more complex system.

## 4. Total Project Cost

- **Phase 1:** $1,200
- **Phase 2:** $300
- **Total after Phase 2:** $1,500

Phase 1 can be completed first as the main build. Phase 2 can then be added afterward to complete the payment integration and extra improvements.

## 5. Payment Terms

To begin Phase 1, payment for the Phase 1 scope is required.

Payment details can be shared once the Phase 1 scope is approved.

## 6. User Roles

The platform will have two main user roles.

### Admin

The admin can:

- Manage workers.
- Manage service categories.
- Create training tracks.
- Approve worker readiness.
- Create opportunities.
- Assign workers.
- Review submitted work.
- Track payouts.
- View dashboard activity.

### Worker

Workers can:

- View their profile and current status.
- View training requirements.
- See assigned opportunities.
- Update work progress.
- Submit work notes, files, or links.
- View payout records.

## 7. Expected Workflow

1. Admin adds a worker.
2. Admin places the worker into a training track.
3. Worker completes training checklist items.
4. Admin reviews and approves the worker for a service category.
5. Admin creates an opportunity.
6. Platform shows eligible workers.
7. Admin assigns the opportunity.
8. Worker completes and submits the work.
9. Admin reviews the submission.
10. Work is marked as completed.
11. Payout record is updated.
12. Admin marks payout as paid, or Phase 2 payment flow is used after Paystack is added.
